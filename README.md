# Golf 2 — My Golf Lounge 간결판

[My Golf Lounge](https://github.com/supok00/golf-lounge)의 등록 값·통계·분석을 모두 훑어, **같은 것을 두 번 묻거나 보여 주는 곳을 정리한 화면**입니다.

**주소**: https://supok00.github.io/golf2/ · 기록은 **golf-lounge 저장소**(`supok00/golf-lounge`의 `data/`)를 그대로 읽고 씁니다. 어느 화면에서 저장해도 양쪽에 보입니다. 토큰도 golf-lounge 저장소 권한이면 됩니다.

## 정리한 것 (18곳)

| 위치 | 겹치던 것 | golf2에서 |
|---|---|---|
| 등록 값 | FW 안착(○/×)과 티샷 미스(L·R·H·S·-) — 같은 사실을 두 칸에 | 「티샷 결과」 한 칸, FW ○/×는 자동 |
| 등록 값 | 온그린 타수 — 타수−퍼트로 계산되는 값 | 입력칸 제거(자동 계산·저장은 유지) |
| 등록 값 | 숏게임 성공 ○/× — 자동 판정되는 값 | 입력칸 제거 |
| 등록 값 | 그린 미스 방향 — GIR 홀에서는 늘 「-」 | GIR 홀은 잠금 |
| 스코어카드 | FW 줄·티샷 미스 줄, 온그린 타수 줄·GIR 줄 | 「티샷」 한 줄, 온그린 줄 제거 |
| 홈 | 실력 진단 표와 7영역 육각형(FW·GIR·스크램블·퍼트·3퍼트가 두 기준에) | 한 표에 목표·판정·점수 |
| 홈 | 강점·약점 목록(판정 열의 반복), 파 유형·전후반 문장(홀·파와 같음) | 「먼저 볼 것」 한 상자 |
| 설정 | 목표 기준값과 육각형 점수 기준(같은 지표 두 표, 단위도 다름) | 「지표 기준」 한 표, % · 라운드당으로 통일 |
| 설정·홈 | 퍼트 수(라운드당)와 홀당 퍼트 | 한 줄(라운드당) |
| 분석 | 상세 분석 ④ 파 유형별 = 홀·파 「파 유형별」 | 삭제 |
| 분석 | 상세 분석 ⑥ 홀 난이도·전후반 | 홀·파로 이동 |
| 분석 | 통계 평균 타수 KPI = 홈 평균 타수 | 삭제 |
| 분석·인사이트 | 통계 「자주 가는 골프장」 = 인사이트 지역별 골프장 표 | 지역 표 「전체 골프장」으로 합침 |
| 인사이트 | 최근 90일 표 = 공통 필터 「최근 90일」 | 삭제 |
| 인사이트 | 올해 골프장 KPI = 홈 방문 골프장 | 삭제 |
| 홈·분석 | 「타수 추이」 두 개(라운드별 / 기간별) | 둘 다 두고 이름 구분 |
| 메뉴 | 10개(통계·홀파·상세, 입력·붙여넣기 따로) | 7개: 분석·등록 하위 탭 |

그대로 둔 것: 거리·핸디캡(이전 라운드에서 불러오기), 라운드별 지역(사용자 결정), 스코어 유형(홀 단위)과 스코어 구간(라운드 단위), 라운드 상세의 카드와 7영역 표.

## 저장 형식은 golf-lounge와 같음

- 「티샷 결과」 FW 안착은 `miss: "-"`, `fw: 1`로 저장(golf-lounge와 같은 값).
- 온그린 타수(`ong`)·숏게임 성공(`sg`)은 입력칸만 없고 자동 계산해 저장합니다.
- 설정의 지표 기준은 화면에서만 %·라운드당으로 보이고, 저장은 golf-lounge 형식(0~1, 홀당)입니다.
